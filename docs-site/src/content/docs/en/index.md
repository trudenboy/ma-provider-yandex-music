Music Assistant supports [Yandex Music](https://music.yandex.ru) — a music streaming service.
The provider is created and maintained by [TrudenBoy](https://github.com/TrudenBoy).

Built on top of the [yandex-music](https://github.com/MarshalX/yandex-music-api) library (an unofficial Yandex Music API client).

:::caution[Disclaimer]
This is an unofficial implementation and is not affiliated with Yandex.
:::



## Features


| Feature | Support |
|:--------|:---------:|
| Artists, Albums, Tracks, Playlists | ✅ |
| Catalog search | ✅ |
| Library sync (bidirectional) | ✅ |
| [Home screen recommendations](features/recommendations/) | ✅ |
| [My Wave / Radio Mode](features/my-wave/) | ✅ |
| [Radio stations / Rotor](features/radio/) | ✅ |
| [Similar tracks](features/similar-tracks/) | ✅ |
| [Lyrics](features/lyrics/) | ✅ |
| [Picks and mixes](features/picks-and-mixes/) | ✅ |
| [Browse catalog](features/browse/) | ✅ |
| [Audio quality up to Lossless FLAC](features/audio-quality/) | ✅ |
| Multiple simultaneous accounts | ✅ |
| Maximum quality | Lossless FLAC (with Yandex Plus subscription) |
| Authentication method | OAuth token |
