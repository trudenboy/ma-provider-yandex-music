The provider gives access to **Yandex Music radio stations** powered by the Rotor engine — the same engine behind My Wave and themed waves in the official app.

## Access

**Browse → Yandex Music → Radio**

## Station Categories

### Personal Waves

Your personal radio stations from the Rotor dashboard. Built based on your listening history and preferences. Available only after sufficient listening history has accumulated in the account.

### Featured Waves

Curated wave categories from the Yandex Music editorial team — ready-made themed collections.

### AI Sets

Collections of radio stations generated by AI based on Yandex Music landing blocks. Updated by Yandex automatically.

### Themed Stations

| Category | Description |
|:----------|:---------|
| **Genres** | Rock, Jazz, Classical, Electronic, Hip-hop, and more |
| **Mood** | Relaxing, Energetic, Sad, Romantic, and more |
| **Activity** | Workout, Focus, On the go, Morning, and more |
| **Era** | 80s, 90s, 2000s, Retro |
| **Local** | Regional and language-based collections |

## How Stations Work

Each station is an **infinite stream of tracks** selected by Rotor:

1. The provider requests a batch of tracks from the Rotor API for the selected station.
2. With each track play, feedback is sent (start / end / skip) — Rotor improves the next recommendations.
3. When a batch ends, the next one is loaded automatically.
4. Each station maintains independent state — you can listen to different stations from different accounts simultaneously.

## Difference from My Wave

| | My Wave | Radio Station |
|:---|:----------|:------------|
| Personalization | Based on your overall taste | Based on the selected theme/genre/mood |
| Access | Browse → My Wave | Browse → Radio → *category* |
| Feedback | Yes | Yes |
