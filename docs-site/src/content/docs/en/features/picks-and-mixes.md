---
title: Picks and Mixes
---

The provider gives access to two types of curated Yandex Music playlists: **Picks** and **Mixes**.

## Access

**Browse → Yandex Music → For You → Picks / Mixes**

## Picks

Picks are editorial playlists organized by thematic tags.

### Categories

| Category | Tags |
|:----------|:-----|
| **Mood** | Relaxing, Sad, Romantic, Party, Chill, … |
| **Activity** | Workout, Focus, Morning, Evening, On the go, Background, … |
| **Era** | 80s, 90s, 2000s, Retro |
| **Genre** | Rock, Jazz, Classical, Electronic, R&B, Hip-hop, Top, … |

### Dynamic Tag Discovery

The tag list is not hard-coded — the provider fetches it via the Yandex Music Landing API:
- Empty categories (with no playlists) are hidden automatically.
- New tags appear without a provider update.
- Results are cached for 1 hour.

## Mixes

Mixes are seasonal playlists generated by Yandex Music algorithms.

| Mix | When available |
|:-----|:---------------|
| Winter | December–February |
| Spring | March–May |
| Summer | June–August |
| Autumn | September–November |
| New Year | December–January |

The current seasonal mix is determined automatically by month and appears in the recommendations section (Discover), refreshed every 6 hours.
