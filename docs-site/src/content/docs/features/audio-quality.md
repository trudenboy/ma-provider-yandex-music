---
title: Lossless FLAC
---

Провайдер поддерживает потоковую передачу в формате **Lossless FLAC** (16-bit, 44.1 kHz).

## Требования

- Активная подписка **Яндекс Плюс** или **Яндекс Музыка**
- Качество выбирается автоматически по возможностям сети

## Поддерживаемые форматы

| Формат | Битрейт | Подписка |
|:-------|:--------|:---------|
| FLAC | Lossless | Плюс |
| AAC 256 | ~256 kbps | Любая |
| AAC 128 | ~128 kbps | Любая |
