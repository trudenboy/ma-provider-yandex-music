Провайдер реализует полноценный **Browse** — навигацию по каталогу Yandex Music прямо из Music Assistant.

## Структура Browse

```
Yandex Music
├── Моя волна               ← персональный бесконечный поток
├── Радио                   ← радиостанции на базе Rotor
│   ├── Персональные        ← ваши персональные волны (дэшборд Rotor)
│   ├── Избранные волны     ← кураторские категории волн
│   ├── AI Сеты             ← AI-сгенерированные наборы волн
│   ├── Жанры
│   ├── Настроение
│   ├── Активность
│   ├── Эпоха
│   └── Местное
├── Для вас                 ← кураторские подборки
│   ├── Подборки            ← по настроению, активности, эпохе, жанру
│   └── Миксы               ← сезонные плейлисты
├── Коллекция               ← ваша личная библиотека
│   ├── Мне нравится        ← виртуальный плейлист лайкнутых треков
│   ├── Мои исполнители
│   ├── Мои альбомы
│   └── Мои плейлисты
├── Чарт                    ← Топ треков Яндекс Музыки
├── Новинки                 ← свежие альбомы и синглы
└── Новые плейлисты         ← свежие плейлисты
```

Имена разделов автоматически переключаются между русским и английским в зависимости от настройки локали в Music Assistant.

## Описание разделов

### Моя волна

Персональный бесконечный поток треков на основе Rotor API. Загружается батчами, дубликаты автоматически фильтруются. Подробнее — [Моя волна](my-wave/).

### Радио

Радиостанции Яндекс Музыки на базе движка Rotor. Каждая станция — бесконечный поток, персонализированный по выбранному параметру. Подробнее — [Радио](radio/).

### Для вас — Подборки и Миксы

Кураторские и алгоритмические плейлисты, организованные по тегам (настроение, активность, эпоха, жанр) и сезонам. Теги обнаруживаются динамически через Landing API — пустые категории скрываются автоматически. Подробнее — [Подборки и миксы](picks-and-mixes/).

### Коллекция

Ваша личная библиотека: лайкнутые треки (виртуальный плейлист с лимитом), исполнители, альбомы и плейлисты. Лайки синхронизируются двунаправленно — поставить или снять лайк можно прямо из MA.

### Чарт, Новинки, Новые плейлисты

Актуальные подборки из каталога Яндекс Музыки с кэшированием 1 час.
