---
title: Просмотр каталога (Browse)
---

Провайдер реализует полноценный **Browse** — навигацию по каталогу Yandex Music прямо из Music Assistant.

## Разделы Browse

| Раздел | Описание |
|:-------|:---------|
| Моя волна | Персональные рекомендации |
| Новые релизы | Свежие альбомы и синглы |
| Чарты | Топ-100 треков |
| Подборки | Редакционные плейлисты |
| Миксы | Алгоритмические плейлисты |
