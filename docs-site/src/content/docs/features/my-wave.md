---
title: Моя волна (Рекомендации)
---

Провайдер поддерживает персонализированные рекомендации через **Моя волна** — бесконечный поток музыки на основе вашего вкуса.

## Доступ

В Music Assistant откройте раздел **Browse → Yandex Music → Моя волна**.

## Типы волн

- **Моя волна** — персональный поток
- **Волна по исполнителю** — стиль конкретного артиста
- **Волна по альбому/треку** — схожие треки
