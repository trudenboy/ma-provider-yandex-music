---
title: Моя волна
---

**Моя волна** — персональный бесконечный поток треков, формируемый движком рекомендаций Яндекс Музыки (Rotor). Поток обновляется в реальном времени на основе вашей истории прослушивания и лайков.

## Доступ

- **Browse:** откройте **Browse → Yandex Music → Моя волна** для просмотра плейлиста.
- **Рекомендации (Discover):** «Моя волна» также появляется на главном экране MA и обновляется каждые 10 минут.

## Как это работает

Провайдер использует Rotor API Яндекс Музыки — тот же движок, что стоит за «Моей волной» в официальном приложении:

1. Треки загружаются батчами (по несколько штук за запрос).
2. Уже воспроизведённые треки отфильтровываются — дубликаты не появляются.
3. При каждом воспроизведении трека провайдер отправляет feedback в Rotor (старт / конец / пропуск) — это улучшает персонализацию.
4. Плейлист поддерживает пагинацию: в Browse можно подгружать ещё треки.

## Настройка лимита

По умолчанию загружается не более **150 треков**. Это значение можно изменить в настройках провайдера:

**Settings → Yandex Music → My Wave — максимум треков** (расширенные настройки, диапазон 10–1000).

Меньшее значение — быстрее загрузка. Большее — длиннее непрерывный поток без повторов.

## Feedback и персонализация

Провайдер автоматически отправляет в Rotor:
- **start** — трек начал воспроизводиться.
- **end** — трек дослушан до конца.
- **skip** — трек пропущен.

Этот feedback влияет на будущие рекомендации точно так же, как в официальном приложении.
