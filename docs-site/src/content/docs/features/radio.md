title: Радио (Rotor)
---

Провайдер предоставляет доступ к **радиостанциям Яндекс Музыки** на базе движка Rotor — того же, что стоит за «Моей волной» и тематическими волнами в официальном приложении.

## Доступ

**Browse → Yandex Music → Радио**

## Категории станций

### Персональные волны

Ваши персональные радиостанции из дэшборда Rotor. Формируются на основе истории прослушивания и предпочтений. Доступны только после накопления достаточной истории в аккаунте.

### Избранные волны

Кураторские категории волн от редакции Яндекс Музыки — готовые тематические подборки.

### AI Сеты

Коллекции радиостанций, сгенерированные AI на основе лендинговых блоков Яндекс Музыки. Обновляются Яндексом автоматически.

### Тематические станции

| Категория | Описание |
|:----------|:---------|
| **Жанры** | Рок, Джаз, Классика, Электроника, Хип-хоп и другие |
| **Настроение** | Расслабляющее, Бодрящее, Грустное, Романтическое и другие |
| **Активность** | Тренировка, Концентрация, В дороге, Утро и другие |
| **Эпоха** | 80-е, 90-е, 2000-е, Ретро |
| **Местное** | Региональные и языковые подборки |

## Как работают станции

Каждая станция — **бесконечный поток треков**, подобранных Rotor:

1. Провайдер запрашивает у Rotor API батч треков для выбранной станции.
2. При воспроизведении каждого трека отправляется feedback (start / end / skip) — Rotor улучшает следующие рекомендации.
3. При окончании батча автоматически загружается следующий.
4. Каждая станция ведёт независимое состояние — можно одновременно слушать разные станции с разных аккаунтов.

## Отличие от Моей волны

| | Моя волна | Радиостанция |
|:|:----------|:------------|
| Персонализация | По вашему вкусу в целом | По выбранной теме/жанру/настроению |
| Доступ | Browse → Моя волна | Browse → Радио → *категория* |
| Feedback | Да | Да |
