## Авторизация

Откройте **Music Assistant → Настройки → Музыкальные источники**, добавьте **Yandex Music** и выберите способ входа:

| Способ | Описание |
|:-------|:---------|
| **QR-код** *(по умолчанию)* | Отсканируйте контрастный QR-код приложением Яндекса и подтвердите вход. |
| **Device Code** | Откройте адрес из жёлтой карточки и введите на этой странице крупный код. |
| **Токен (вручную)** | Вставьте существующий токен Яндекс Музыки. Токен проверяется перед сохранением, но не обновляется автоматически. |

Просроченные QR- и Device-коды обновляются автоматически. Весь интерактивный процесс завершается через 15 минут; для новой попытки запустите **Reconfigure**.

**Remember session** применяется к QR и Device Code и по умолчанию включён. Провайдер сохраняет данные сессии, необходимые для автоматического обновления музыкального токена. Если выключить параметр, сохранится только текущий музыкальный токен и после его истечения потребуется повторная авторизация. При ручном входе всегда сохраняется только введённый токен.

:::danger[Безопасность токена]
OAuth-токен даёт доступ к вашему аккаунту Яндекс Музыки. Не передавайте его третьим лицам и не вводите на сторонних сайтах. Храните токен как пароль.
:::

## Повторная авторизация и замена токена

Чтобы заново запустить QR, Device Code или ручной вход, откройте меню нужного экземпляра провайдера и выберите **Reconfigure**. Удалять и создавать провайдер повторно не требуется.

В расширенных настройках также есть одноразовое поле **Replace Yandex Music token**. Оставьте его пустым, чтобы сохранить текущие данные. После сохранения новый токен проверяется, переносится в защищённое хранилище и удаляется из поля. Неверный токен отбрасывается без перезаписи рабочих данных.

## Получение токена для ручного входа

Ручной вход необязателен. При использовании QR или Device Code самостоятельно копировать токен не нужно.

1. Откройте [Yandex OAuth](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d).
2. Войдите и разрешите доступ, если появится запрос.
3. В адресе после перенаправления скопируйте значение между `access_token=` и следующим `&`.
4. Выберите **Токен (вручную)** в пошаговой настройке и вставьте значение.

## Параметры

| Параметр | По умолчанию | Описание |
|:---------|:-------------|:---------|
| **Audio quality** | Balanced | Efficient, Balanced, High или Superb. Подробнее — [Качество звука](features/audio-quality/). |
| **My Wave maximum tracks** *(расш.)* | 150 | Число треков в плейлисте «Моя волна». Диапазон: 10–1000. |
| **My Wave presets** *(расш.)* | Нет | Именные пресеты из фильтров разнообразия, настроения и языка. Сохранённые пресеты доступны в **Радио → Мои пресеты**. |
| **Liked Tracks maximum tracks** *(расш.)* | 200 | Число треков в виртуальном плейлисте «Понравившиеся». Диапазон: 50–2000. Большие значения увеличивают время загрузки и риск CAPTCHA. |
| **API Base URL** *(расш.)* | `https://api.music.yandex.net` | Менять только при изменении адреса API Яндексом. |
| **Restrictive rate limits** *(расш.)* | Выключено | Более безопасное ограничение запросов для VPS, VPN и адресов дата-центров. |
| **Replace Yandex Music token** *(расш.)* | Пусто | Необязательная одноразовая замена токена, описанная выше. |

Параметры, помеченные *(расш.)*, отображаются в режиме **Show advanced settings**.
