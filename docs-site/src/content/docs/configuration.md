## Шаг 1 — Получите токен

Провайдер использует OAuth-токен для авторизации в Yandex Music API. Есть два способа его получить.

### Способ 1: Утилита yandex-music-token (рекомендуется)

Автоматический способ через официальную утилиту:

```bash
pip install yandex-music-token
python -m yandex_music_token
```

Следуйте инструкциям в терминале — введите логин/пароль или войдите через браузер. Токен будет выведен в терминал после успешной авторизации.

### Способ 2: Из браузера вручную

1. Откройте [music.yandex.ru](https://music.yandex.ru) и войдите в аккаунт.
2. Откройте DevTools (F12) → вкладка **Application** → **Cookies** → `music.yandex.ru`.
3. Найдите cookie `Session_id` и скопируйте его значение.
4. Используйте расширение для браузера [Yandex Music Token](https://github.com/MarshalX/yandex-music-token/releases) — оно автоматически извлекает OAuth-токен из сессии.

Скопируйте итоговый OAuth-токен — длинную строку из букв и цифр.

## Шаг 2 — Добавьте провайдер в Music Assistant

<Steps>
1. Откройте **Music Assistant → Настройки → Источники музыки**.
2. Нажмите **«+ Добавить»** и выберите **Yandex Music**.
3. Вставьте скопированный токен в поле **«Yandex Music Token»**.
4. Выберите предпочитаемое **качество звука** (см. ниже).
5. Нажмите **«Сохранить»**.
6. MA подключится к Yandex Music и начнёт синхронизацию библиотеки.
</Steps>

## Параметры

| Параметр | По умолчанию | Описание |
|:---------|:-------------|:---------|
| **Yandex Music Token** | — | OAuth-токен авторизации. Обязательный. |
| **Сбросить авторизацию** | — | Очищает сохранённый токен для повторного входа. |
| **Качество звука** | Balanced | Уровень качества: Efficient / Balanced / High / Superb. Подробнее — [Качество звука](features/audio-quality/). |
| **My Wave — максимум треков** *(расш.)* | 150 | Сколько треков загружается для плейлиста «Моя волна». Меньше → быстрее загрузка. Диапазон: 10–1000. |
| **Мне нравится — максимум треков** *(расш.)* | 500 | Максимум треков в виртуальном плейлисте «Мне нравится». Большие значения замедляют загрузку. Диапазон: 50–2000. |
| **API Base URL** *(расш.)* | `https://api.music.yandex.net` | Базовый URL API. Менять только если Яндекс изменит эндпоинт. |

Параметры, помеченные *(расш.)*, отображаются в режиме «Расширенные настройки».

## Если токен перестал работать

Токен может истечь через некоторое время. Симптомы: провайдер перестаёт воспроизводить треки или показывает ошибку авторизации.

**Решение:**
1. В MA откройте настройки провайдера Yandex Music.
2. Нажмите **«Сбросить авторизацию»**.
3. Получите новый токен по инструкции выше (Шаг 1).
4. Введите новый токен и нажмите **«Сохранить»**.
