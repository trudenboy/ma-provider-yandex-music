# Yandex Music Provider for Music Assistant

[Yandex Music](https://music.yandex.ru) provider for [Music Assistant](https://music-assistant.io).
Contributed and maintained by [TrudenBoy](https://github.com/TrudenBoy).

**Source:** [trudenboy/ma-provider-yandex-music](https://github.com/trudenboy/ma-provider-yandex-music)

---

## Features

| Feature | Supported |
|---------|-----------|
| Browse Library | Yes |
| Search | Yes |
| Playback | Yes |
| Radio Mode (My Wave) | Yes |
| Recommendations | Yes |
| Lyrics | Yes |
| Picks & Mixes | Yes |
| FLAC streaming | Yes |
