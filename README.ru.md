# Провайдер Яндекс Музыки для Music Assistant

[English](README.md) | Русский

> Стримингу музыки из Яндекс Музыки с поддержкой поиска, просмотра и воспроизведения.

## Возможности

| Функция | Описание |
|---------|----------|
| Обзор | Мне нравится, Моя волна, Подборки и Миксы, Исполнители, Альбомы, Плейлисты |
| Поиск | Треки, исполнители, альбомы, плейлисты |
| Воспроизведение | AAC (64–192 кбит/с), MP3 (320 кбит/с), FLAC (без потерь) |
| Синхронизация библиотеки | «Мне нравится» → библиотека MA |
| Режимы стриминга | Прямой / буферизованный / предварительная загрузка |

## Совместимость

| Версия провайдера | Мин. версия MA | Протестировано с MA |
|-------------------|----------------|---------------------|
| 2.x.x             | 2.7.0          | 2.7.0b1             |

## Установка

Устанавливается автоматически как часть Music Assistant.

### Настройка

1. Настройки → Музыкальные источники → Добавить источник → Яндекс Музыка
2. Введите OAuth-токен Яндекс Музыки
3. Выберите качество стриминга
4. Сохраните
